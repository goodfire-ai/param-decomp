Layerwise-Parallel Training Step

This visual assumes the objective is standardized to layer-local faithfulness, layer-local CI importance/frequency minimality, and layerwise reconstruction only. Full-model component losses are removed. Each layer group owns a frozen target replica, one layer's decomposition params, one layer's CI function, its optimizer, and a shard of data.

What disappears No full-model stochastic subset branch, no PPGD branch, no global CI output tensor, and no all-layer retained loss-graph join.
What remains expensive Layerwise reconstruction still needs the target's downstream computation from layer l to logits, with autograd through the frozen suffix.
Clean communication boundary Only gradients for the current layer's trainable state are reduced across the N GPUs in that layer group.

Conceptual Step Formula

per-GPU live state ~= frozen_target + layer_trainable_state + layer_optimizer_state + local_batch_caches + layer_CI_graph + one layerwise_recon_graph

Crucially, this does not include optimizer state for other layers and does not include retained graphs for other layers' losses.

Tradeoff

This strategy buys memory and dependency simplicity by replicating frozen target compute across layer groups. Since the target is frozen and has no optimizer state, that can be the right trade if HBM and optimizer state were the binding constraints.
