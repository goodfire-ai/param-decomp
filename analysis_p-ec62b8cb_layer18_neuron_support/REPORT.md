## Method

Each subcomponent is a rank-1 outer product `W_c = U[c,:] ⊗ V[:,c]`. For each subcomponent the residual-stream-touching vector is normalised to unit L2 norm and the MLP-neuron-touching vector is rescaled by that same norm (the outer product is scale-invariant, so this fixes a canonical scale). The **connecting weight** to neuron *n* is then the entry of the rescaled MLP-side vector at index *n*. Subcomponents are ranked by `|connecting weight|`.

- `gate_proj` / `up_proj`: residual side = `V[:,c]` (d_model=4096); MLP side = `U[c,:]` (d_ffn=14336). Connecting weight = `U[c,n]·‖V[:,c]‖`.
- `down_proj`: residual side = `U[c,:]` (d_model); MLP side = `V[:,c]` (d_ffn). Connecting weight = `V[n,c]·‖U[c,:]‖`.
