Conceptual DAG Of One SPD Training Step

Each node is a computation that may allocate local working memory and may also produce state that must remain live for downstream losses or backward. The resource bars are normalized pressure units, not measured GB: they show how resident state, carried tensors, retained autograd graphs, and node-local transients stack up along the step.

resident weights, optimizer state, persistent PGD sources; exists before the step starts.
carried batch-dependent tensors that later nodes still need: logits, cached site inputs, CI scores.
graph retained autograd state needed by a later backward or gradient extraction.
current temporary work for the node currently executing; this is often where peak HBM occurs.

Why It Matters

Read the mini-bars inside each node as: base resident state plus carried tensors plus retained graphs plus current transient. The exact width is conceptual; the relative shape is the important part.

Resource Recurrence

live_after(node) = resident_state + carried_outputs_needed_later + retained_autograd_graphs node_peak = live_before(node) + node_local_workspace + node_forward_activations step_peak ~= max(node_peak)

In this loop, resident state is not the whole story. The painful part is that several branches need the same CI outputs, target logits, and weight deltas, while reconstruction losses retain separate masked forward graphs until the total backward unless they are explicitly streamed.

Two Meanings Of "Cumulative"

Logical cumulative: downstream dependencies expand monotonically until the loss join. If a node consumes target logits, CI scores, and deltas, those tensors must exist somewhere.
HBM cumulative: memory only grows monotonically if graphs are retained. Warmup graphs can be freed. Layerwise and subset graphs are retained in the current loss accumulation pattern, so they are the main cumulative risk.

Critical implication 1 Sharding resident state solves the fixed 4B-CI problem, but it does not remove the O(B_rank x S x fanout) retained activation pattern.
Critical implication 2 The layerwise branch is naturally additive. Streaming backward over its terms would turn cumulative graph memory into repeated current-work memory.
Critical implication 3 PPGD warmups are serial by source-update dependency. They are not as cumulative as layerwise loss, but they add unavoidable time and local peaks.
