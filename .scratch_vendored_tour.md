# Guided tour: the vendored ComponentModel (`feature/multipool`)

A vendored, checkpoint/FSDP/compile-friendly replacement for the hook-based `ComponentModel`: masks are threaded as **forward arguments** instead of injected via side-channel `register_forward_hook`, so the masked forward is a pure function of `(x, mask_info)` that `torch.utils.checkpoint` can save and replay.

---

### 1. The heart: replace-and-route as a module's own `forward`

`mask_info is None` → behave as the frozen target; else run the components and `torch.where` between component output and target output. `component_modules.py`:

```python
def forward(self, x, mask_info, component_acts_cache=None):
    if mask_info is None:
        assert component_acts_cache is None, "component_acts_cache needs an active mask"
        return self.target_forward(x)
    components_out = self.components(
        x, mask=mask_info.component_mask,
        weight_delta_and_mask=mask_info.weight_delta_and_mask,
        component_acts_cache=component_acts_cache,
    )
    if mask_info.routing_mask == "all":
        return components_out
    return torch.where(mask_info.routing_mask[..., None], components_out, self.target_forward(x))
```

The frozen-target path is the only per-subclass piece:

```python
class ComponentLinear(_ComponentModule):
    def target_forward(self, x): return F.linear(x, self.target_weight, self.bias)

class ComponentEmbedding(_ComponentModule):
    def target_forward(self, x): return self.target_weight[x]
```

---

### 2. Contrast: the old side-channel hook this replaces

`param_decomp/component_model.py` — the same replace-and-route logic, but smuggled in as a forward hook return value, with masks read from closure state rather than passed in:

```python
handle = target_module.register_forward_hook(hook, with_kwargs=True)
...
def _components_and_cache_hook(self, _module, args, kwargs, output, ..., mask_info, ...):
    x = args[0]
    components_out = components(x, mask=mask_info.component_mask, ...)
    final_out = (components_out if mask_info.routing_mask == "all"
                 else torch.where(mask_info.routing_mask[..., None], components_out, output))
    return final_out   # PyTorch swaps this in for the original output
```

Hooks mutate output post-hoc and capture masks via closure — invisible to `checkpoint`'s recompute. Threading them as args (snippet 1) fixes that.

### 3. Mask lookup by path — `_proj`

Each component leaf knows its own `path`; `_proj` routes the right `mask_info` to it and optionally records its input/output acts. `gpt2.py`:

```python
def _proj(module, x, mask_infos, collect, collect_outputs=None):
    if isinstance(module, _ComponentModule):
        if collect is not None:
            collect[module.path] = x
        mask_info = None if mask_infos is None else mask_infos.get(module.path)
        out = module(x, mask_info)
        if collect_outputs is not None:
            collect_outputs[module.path] = out
        return out
    return module(x)   # plain leaf, applied unchanged
```

### 4. The crux: `mask_infos` passed as a `checkpoint(...)` argument

Because the masks are a forward arg, the block loop can hand them to `torch.utils.checkpoint`, which saves+replays them across the recompute boundary. `ComponentGPT2.forward`:

```python
if self._use_activation_checkpointing and collect is None and collect_outputs is None:
    for block in blocks:
        x = checkpoint(block, x, mask_infos, use_reentrant=False)
else:
    for block in blocks:
        x = block(x, mask_infos, collect, collect_outputs)
x = self.ln_f(x)
return x if self._bypass_lm_head else self.lm_head(x)
```

### 5. Dynamic one-off restructuring: `componentize_gpt2`

Freeze the target, swap decomposition leaves for in-tree component modules, then re-point attn/MLP/block/model forwards via `__class__` reassignment (no new `__init__`):

```python
def componentize_gpt2(model, components):
    for param in model.parameters():
        param.requires_grad_(False)
    for path, comp in components.items():
        parent = model.get_submodule(path.rpartition(".")[0])
        target_module = getattr(parent, path.rpartition(".")[2])
        new = (ComponentLinear if isinstance(comp, LinearComponents) else ComponentEmbedding)(
            comp, _target_weight(target_module))
        new.path = path
        setattr(parent, path.rpartition(".")[2], new)
    for block in model._h:
        block.attn.__class__ = ComponentCausalSelfAttention
        block.mlp.__class__  = ComponentMLP
        block.__class__      = ComponentBlock
    model.__class__ = ComponentGPT2
    return model
```

### 6. `bypass_lm_head` — another facet threaded explicitly, not hooked

A context that makes `forward` return the post-final-LN hidden state (for fused linear-KL reconstruction) and yields `lm_head.weight`:

```python
@contextmanager
def bypass_lm_head(self):
    self._bypass_lm_head = True
    try:
        yield self.lm_head.weight
    finally:
        self._bypass_lm_head = False
```

### 7. Composition: `LMComponentModel = ComponentGPT2 + ci_fn`

`build` makes components + CI fn from the still-`nn.Linear` target, then componentizes. The model owns the forward; the wrapper adds the CI fn. `component_model.py`:

```python
@classmethod
def build(cls, target_model, decomposition_targets, ci_config, sigmoid_type):
    module_to_c = {t.module_path: t.C for t in decomposition_targets}
    components = make_components(target_model, module_to_c)
    ci_fn = make_ci_fn_wrapper(target_model=target_model, module_to_c=module_to_c,
                               components=components, ci_config=ci_config)
    model = componentize_gpt2(target_model, components)   # freezes + swaps in same Components
    return cls(model, ci_fn, sigmoid_type)
```

Pool lifecycle is just dropping params: `drop_ci_fn()` (pools that get CI over NCCL) and `drop_components()` (the CI pool holds no V/U).

g_plain = run(False)
g_ckpt  = run(True)
